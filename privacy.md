# Privacy Policy - rclone-backup

Last updated: 2026-11-18

rclone-backup is a private OAuth client used by a single person, its owner, to back up their own files to their own Google Drive with the open-source tool rclone.

## What data is accessed

The client asks for access to the owner's Google Drive so rclone can upload, list and update backup files there. It does not request access to any other Google data.

## How data is used and stored

Files go directly from the owner's computer to the owner's Google Drive. The OAuth token is stored only in the rclone configuration file on the owner's computer. No server run by the developer receives, stores or processes the files or the token.

## Sharing

No data is sold, shared with third parties, or used for advertising, analytics or AI training.

## Other users

This client is not offered to the public. No one other than the owner is expected to sign in.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions

## Contact

Via the developer contact listed on the Google OAuth consent screen, or the GitHub profile https://github.com/starjw2010-cloud
